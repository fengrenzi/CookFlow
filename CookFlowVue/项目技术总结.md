### 1. 用户表（users）
| 字段名 | 数据类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| `id` | `INT` | `PRIMARY KEY AUTO_INCREMENT` | 用户ID |
| `username` | `VARCHAR(50)` | `UNIQUE NOT NULL` | 用户名 |
| `email` | `VARCHAR(100)` | `UNIQUE NOT NULL` | 邮箱 |
| `password_hash` | `VARCHAR(255)` | `NOT NULL` | 密码哈希 |
| `phone` | `VARCHAR(20)` | | 手机号 |
| `bio` | `TEXT` | | 个人简介 |

| `last_login` | `TIMESTAMP` | | 最后登录时间 |

## 二、后端接口设计

### 1. 用户接口

#### 1.1 用户注册
- **URL**: `/api/users/register`
- **方法**: `POST`
- **参数**:
  - `username`: `string` - 用户名（必填）
  - `email`: `string` - 邮箱（必填，唯一）
  - `password`: `string` - 密码（必填，至少6位）
  - `phone`: `string` - 手机号（可选）
- **返回**:
  ```json
  {
    "code": 200,
    "message": "注册成功",
    "data": {
      "id": 1,
      "username": "user1",
      "email": "user1@example.com"
    }
  }
  ```

#### 1.2 用户登录
- **URL**: `/api/users/login`
- **方法**: `POST`
- **参数**:
  - `email`: `string` - 邮箱（必填）
  - `password`: `string` - 密码（必填）
- **返回**:
  ```json
  {
    "code": 200,
    "message": "登录成功",
    "data": {
      "token": "jwt_token_here",
      "user": {
        "id": 1,
        "username": "user1",
        "email": "user1@example.com",
        "avatar": "https://example.com/avatar.jpg"
      }
    }
  }
  ```

#### 1.3 获取用户信息
- **URL**: `/api/users/profile`
- **方法**: `GET`
- **参数**: 无（需要JWT token）
- **返回**:
  ```json
  {
    "code": 200,
    "data": {
      "username": "user1",
      "email": "user1@example.com",
      "phone": "138****1234",
      "bio": "个人简介",
      "registerDate": "2024-01-01",
      "avatar": "https://example.com/avatar.jpg"
    }
  }
  ```

#### 1.4 更新用户信息
- **URL**: `/api/users/profile`
- **方法**: `PUT`
- **参数**:
  - `username`: `string` - 用户名（可选）
  - `phone`: `string` - 手机号（可选）
  - `bio`: `string` - 个人简介（可选）
  - `avatar`: `file` - 头像文件（可选）
- **返回**:
  ```json
  {
    "code": 200,
    "message": "更新成功",
    "data": {
      "username": "user1_new",
      "phone": "139****5678",
      "bio": "新的个人简介",
      "avatar": "https://example.com/new_avatar.jpg"
    }
  }
  ```


## 四、项目技术栈总结

### 前端技术栈
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **状态管理**: Pinia
- **UI组件库**: Element Plus
- **路由**: Vue Router
- **类型系统**: TypeScript
- **HTTP请求**: Axios (预留接口)
- **样式处理**: CSS/SCSS

### 项目架构特点
1. **组件化设计**: 页面拆分为多个可复用组件
2. **状态管理**: 使用Pinia进行集中式状态管理
3. **TypeScript支持**: 全项目类型安全
4. **响应式设计**: 适配不同屏幕尺寸
5. **模块化结构**: 按功能模块划分目录结构

### 主要功能模块
1. **菜谱系统**: 菜谱浏览、搜索、详情查看
2. **食材系统**: 食材分类、详情、营养信息
3. **书籍系统**: 美食书籍展示、阅读
4. **购物车**: 食材清单生成、管理
5. **AI助手**: 智能问答、菜谱推荐
6. **问答社区**: 问题发布、回答、评论
7. **活动系统**: 活动参与、分享
8. **用户系统**: 注册、登录、个人资料管理
